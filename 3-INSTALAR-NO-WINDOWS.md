# Instalar no Windows (Chrome ou Edge)
1. Abra o endereço do jogo no **Chrome** ou **Microsoft Edge**.
2. Na barra de endereço, clique no ícone de instalar (monitor com seta ⊕), ou:
   - Chrome: **⋮ → Transmitir, salvar e compartilhar → Instalar página como app**
   - Edge: **⋯ → Aplicativos → Instalar este site como um aplicativo**
3. Clique **Instalar**. O jogo abre em janela própria e ganha atalho no Menu Iniciar (e, se quiser, na área de trabalho).
4. Funciona sem manter o navegador aberto e sem internet depois do primeiro carregamento.

Desinstalar: Configurações do Windows → Aplicativos, ou ⋮ dentro da janela do app → Desinstalar.
